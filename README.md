## What's here
- `hyprland/` — window manager config (animations, decoration, keybinds, rules, etc.)
- `scheme/` — color scheme configs
- `scripts/` — helper scripts (fish shell)

 ## Setup
- OS: Arch Linux
- WM: Hyprland
- Shell: fish
